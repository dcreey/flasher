# Spanish stem-changing (radical-changing) verbs

Method: Wiktionary per-pattern category pages (each fully listed on one page) plus Wiktionary conjugation tables; RAE DLE snippets via search (rae.es fetch gave 403). Wiktionary categories include archaic/dialectal entries (marked "arch."), which a modern-Spanish app should skip. Items marked [KB] come from general knowledge, not a fetched source (lower confidence).

## 1. Complete lists by pattern (and derivative families)

### Takeaway
Wiktionary counts: e-ie 188, o-ue 147, e-i 69, e-ie-i 68, o-ue-u 9, u-ue 5, i-ie 4, o-hue 2, e-ye 2. Patterns: -ar/-er verbs only diphthongize (e-ie, o-ue); -ir verbs either raise (e-i), or diphthongize AND raise (e-ie-i, o-ue-u); i-ie is only the -quirir group; u-ue only jugar.

## 2. Regular "false friends" (look like stem-changers but are NOT)
### Takeaway
Absence from all Wiktionary alternation categories above confirms regularity for these (verified by absence, not by individual conjugation tables).

### Cited Findings
- Verified absent from the e-ie/e-i/e-ie-i/o-ue lists (so regular in the stem vowel): pretender, ofender, someter, comer, beber, deber, prender, aprender, vender, temer, meter, romper, pesar, cortar, robar, doblar, soplar, cobrar, colocar, innovar, pegar, recibir, escribir, partir, abrir, subir, vivir, discutir, sufrir, dirigir, escoger, ostentar, amueblar, absorber, mecer, acordarse is NOT false (o-ue). — absence from [e-ie](https://en.wiktionary.org/wiki/Category:Spanish_verbs_with_e-ie_alternation), [o-ue](https://en.wiktionary.org/wiki/Category:Spanish_verbs_with_o-ue_alternation), [e-i](https://en.wiktionary.org/wiki/Category:Spanish_verbs_with_e-i_alternation) lists
- Archaic spellings appear in lists but are not modern changers: recebir (modern recibir is regular).
- Accent-shift verbs are NOT stem changes [KB]: aislar (aíslo), reunir (reúno), ahumar, actuar, enviar, confiar, prohibir.
- Other irregular classes [KB]: oír, oler is o-hue (listed), asir, caber, saber; -ecer/-ducir verbs add -zc-.

### Gaps
